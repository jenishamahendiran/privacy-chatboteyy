# Project Roadmap

## Phase 1 — Working chatbot
- Flask
- Chat UI
- Gemini/local model
- Basic conversation context

## Phase 2 — Privacy
- PII detection
- Masking/redaction
- User-controlled memory
- Delete chat
- Data-retention settings

## Phase 3 — RAG
- Upload PDF/DOCX/TXT
- Chunk documents
- Embeddings
- Vector database
- Retrieve relevant chunks
- Generate grounded answers

## Phase 4 — Security
- Authentication
- HTTPS
- Rate limiting
- Secure API key storage
- Input/output validation
- Prompt-injection defenses

## Phase 5 — Advanced privacy
- Local LLM option
- Local embeddings
- Encrypted local storage
- Privacy dashboard
- "What data was sent?" inspection panel

## Final project idea

"Privacy-first conversational AI assistant with PII protection,
user-controlled memory, and retrieval-augmented generation."
